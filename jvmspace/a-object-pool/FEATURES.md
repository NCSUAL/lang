# Object Pool

## 1. 프로젝트 개요

**객체를 생성, 대여, 반환, 폐기할 수 있는 간단한 Object Pool을 구현한다.**

---

## 2. 기능 구현 목록

### 메뉴

- [x] 사용자에게 메뉴를 출력한다.
  - [x] `1` 객체 대여
  - [x] `2` 객체 반환
  - [x] `3` 객체 폐기
  - [x] `4` Pool 상태 조회
  - [x] `5` Pool 종료
- [x] 메뉴 번호를 입력받는다.
- [x] 숫자가 아닌 입력을 검증한다.
- [x] 존재하지 않는 메뉴 입력을 검증한다.

---

### 객체 생성

- [x] Pool에서 사용할 객체를 구현한다.
- [x] 객체의 식별자를 관리한다.
- [x] 객체 생성을 Factory에 위임한다.
- [x] Factory를 통해 새로운 객체를 생성한다.

---

### 기본 Pool

- [x] Object Pool을 생성한다.
- [ ] 최대 객체 수를 설정한다.
- [ ] 유휴 객체를 관리한다.
- [ ] 사용 중인 객체를 관리한다.

---

### 객체 대여

- [ ] 유휴 객체가 있는 경우 해당 객체를 대여한다.
- [ ] 대여한 객체를 `IDLE`에서 `ACTIVE` 상태로 변경한다.
- [ ] 유휴 객체가 없는 경우 새로운 객체를 생성한다.
- [ ] 생성한 객체를 대여한다.
- [ ] 최대 객체 수를 초과하여 객체가 생성되지 않도록 한다.

---

### 객체 반환

- [ ] 사용 중인 객체를 Pool에 반환한다.
- [ ] 반환 대상이 Pool에서 관리하는 객체인지 검증한다.
- [ ] 반환된 객체의 상태를 Factory를 통해 검증한다.
- [ ] 정상 객체를 유휴 상태로 변경한다.
- [ ] 정상 객체를 다시 사용할 수 있도록 Pool에 보관한다.

---

### 객체 검증

- [ ] Factory에서 객체의 정상 여부를 검증한다.
- [ ] 정상 객체는 Pool에 반환한다.
- [ ] 비정상 객체는 폐기한다.

---

### 객체 폐기

- [ ] 사용 중인 객체를 명시적으로 폐기한다.
- [ ] Factory에 객체 폐기를 위임한다.
- [ ] 폐기한 객체를 Pool의 관리 대상에서 제거한다.
- [ ] 폐기된 객체를 다시 대여할 수 없도록 한다.

---

### Pool 상태 조회

- [ ] 전체 객체 수를 조회한다.
- [ ] 사용 중인 객체 수를 조회한다.
- [ ] 유휴 객체 수를 조회한다.
- [ ] Pool 상태를 사용자에게 출력한다.

---

### 자원 자동 반환

- [ ] 대여 객체를 감싸는 자원 객체를 구현한다.
- [ ] `AutoCloseable`을 구현한다.
- [ ] `close()` 호출 시 객체를 Pool에 반환한다.
- [ ] `try-with-resources`를 통해 객체를 사용할 수 있도록 한다.

---

### 동시성 제어

- [ ] 여러 Thread에서 동시에 객체를 대여할 수 있도록 한다.
- [ ] 여러 Thread에서 동시에 객체를 반환할 수 있도록 한다.
- [ ] 객체 생성 시 최대 객체 수를 초과하지 않도록 동기화한다.
- [ ] 하나의 객체가 여러 Thread에 동시에 대여되지 않도록 한다.

---

### 대기 처리

- [ ] 최대 객체 수에 도달하면 객체 반환을 기다린다.
- [ ] 대기 중인 Thread 수를 관리한다.
- [ ] 객체가 반환되면 대기 중인 Thread를 깨운다.
- [ ] 대기 시간을 설정할 수 있도록 한다.
- [ ] 대기 시간이 초과되면 예외를 발생시킨다.

---

### Pool 상태 조회 확장

- [ ] 대기 중인 Thread 수를 조회한다.
- [ ] 전체 객체 수를 출력한다.
- [ ] 사용 중인 객체 수를 출력한다.
- [ ] 유휴 객체 수를 출력한다.
- [ ] 대기 중인 Thread 수를 출력한다.

---

### Idle 객체 정리

- [ ] 객체의 마지막 반환 시간을 관리한다.
- [ ] 일정 시간 이상 사용되지 않은 Idle 객체를 찾는다.
- [ ] 오래된 Idle 객체를 Factory를 통해 폐기한다.
- [ ] 정리 후 Pool에서 객체를 제거한다.
- [ ] Idle 객체 정리 작업을 주기적으로 실행한다.

---

### Pool 종료

- [ ] Pool의 종료 상태를 관리한다.
- [ ] Pool 종료 기능을 구현한다.
- [ ] 종료 시 유휴 객체를 모두 폐기한다.
- [ ] 종료 후 새로운 객체를 생성하지 않는다.
- [ ] 종료된 Pool에서 객체 대여를 요청하면 예외를 발생시킨다.
- [ ] Idle 객체 정리 작업을 종료한다.

---

## 3. 객체 상태

```text
        borrow
IDLE ───────────→ ACTIVE
 ↑                  │
 │                  │ release
 └──────────────────┘

ACTIVE ── invalidate ──→ DESTROYED
```

---

## 4. 구현 순서

```text
메뉴
 ↓
객체 / Factory
 ↓
기본 Pool
 ↓
객체 대여
 ↓
객체 반환
 ↓
객체 검증 / 폐기
 ↓
Pool 상태 조회
 ↓
try-with-resources
 ↓
동시성 제어
 ↓
대기 / Timeout
 ↓
Idle 객체 정리
 ↓
Pool 종료
```
